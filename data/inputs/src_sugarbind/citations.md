# SugarBind Ligands Export

This file contains a tab-separated export of the ligand table from the SugarBind resource hosted at ExPASy.

## Source

Data were retrieved from the SugarBind ligands page:

- SugarBind ligands: `https://sugarbind.expasy.org/ligands`

SugarBind is a curated resource describing glycan-mediated host–pathogen interactions. The resource states that users should cite the following publication:

> Mariethoz J, Khatib K, Alocci D, Campbell MP, Karlsson NG, Packer NH, Mullen EH, Lisacek F.  
> **SugarBindDB, a resource of glycan-mediated host-pathogen interactions.**  
> _Nucleic Acids Research._ 2016;44(D1):D1243-D1250.  
> doi: 10.1093/nar/gkv1247

## Recommended citation

If you use this exported ligand table in analysis, please cite both:

1. The SugarBind web resource
2. The SugarBindDB publication above

Suggested wording:

> Ligand records were downloaded from the SugarBind ligands page at ExPASy and derived from SugarBindDB, a curated resource of glycan-mediated host–pathogen interactions.
